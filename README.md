# Проект Сервис управления рассылками

Чтобы удержать текущих клиентов бизнеса, часто используются вспомогательные, или «прогревающие», рассылки для
информирования и привлечения.

В этом проекте разработан сервис управления рассылками, администрирования и получения статистики.

## Описание:

Данный проект представляет из себя веб-приложение на Django, которое позволяет пользователям управлять рассылками сообщений для клиентов.
Приложение включает функциональность для создания, просмотра, редактирования и удаления рассылок, а также
отправки сообщений по требованию.

## Установка:

1. Клонируйте репозиторий:

```
https://github.com/KseniyaPestrakova/course_work_4.git
```

2. Установите зависимости:

```
pip install -r requirements.txt
```
